1. 🗄️ Mini Bitcask Key-Value Store

Repository: mini-bitcask-rs

A log-structured key-value storage engine inspired by the Bitcask storage model.

Key Features

Append-only log-based storage architecture.
In-memory BTreeMap indexing.
Key-value operations: SET, GET, and DELETE.
Tombstone-based deletion.
Crash recovery through log replay.
Manual compaction to reclaim obsolete records.
Prefix and range scanning.
File locking using fs4.

Engineering Concepts: Storage engines, indexing, file I/O, serialization, crash recovery, and log-structured storage.

Repository: expr-eval

A lightweight arithmetic expression parser and evaluator implemented in Rust without building an Abstract Syntax Tree (AST).

Key Features

Tokenization using Rust iterators.
Operator precedence and associativity.
Recursive-descent parsing.
Parenthesized expressions.
Integer arithmetic and exponentiation.
Structured error handling.

Engineering Concepts: Parsing, interpreters, recursive algorithms, operator precedence, and language design.
